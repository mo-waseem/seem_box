Use it on YouTube

Install the preview extension using the project's README, under Chrome Extension (Preview).

  1. In Chrome 120 or newer, open chrome://extensions and enable Developer mode.
  2. Choose Load unpacked and select the project's extension folder.
  3. Pair the extension in its toolbar popup using the deployment's extension token, as described in the README. It is separate from this page's browser login.
  4. Reload YouTube, open a video, and choose Summarize, then Summarize Video.

If captions are blocked, open YouTube's Show transcript panel and retry, or paste a transcript in the extension.

This page is protected by the Worker's browser sign-in. No provider keys or extension tokens are entered here.
