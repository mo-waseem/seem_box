[Assistant]: Use an OpenAI-compatible sidecar such as **g4f**.

Add this to `.env.local`:

```env
SEEM_BOX_LLM_PROVIDER=compat
SEEM_BOX_COMPAT_BASE_URL=http://127.0.0.1:8080
SEEM_BOX_COMPAT_MODEL=gpt-4o-mini
SEEM_BOX_COMPAT_API_KEY=
```

Run g4f with Docker:

```bash
docker run --rm \
  -p 8080:8080 \
  -p 7900:7900 \
  --shm-size="2g" \
  hlohaus789/g4f:latest
```

Check available models:

```bash
curl http://127.0.0.1:8080/v1/models
```

If `gpt-4o-mini` is unavailable, replace `SEEM_BOX_COMPAT_MODEL` with one of the returned model IDs. Restart `npm run dev` after changing `.env.local`.

For providers requiring a browser login, open:

```text
http://localhost:7900/?autoconnect=1&resize=scale&password=secret
```

Important: ChatGPT’s free web access is rate-limited, not truly unlimited. g4f and similar browser-session adapters are unofficial and may stop working when ChatGPT changes its site.
